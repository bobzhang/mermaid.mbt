# mermaid.mbt

A port of [Mermaid](https://github.com/mermaid-js/mermaid) — the text-to-diagram
toolkit — to [MoonBit](https://www.moonbitlang.com).

The port is pure MoonBit: it has no DOM and no JavaScript dependency, and
renders diagrams straight to SVG text on every backend.

Work in progress. See "Status" below for what is ported.

Nothing is ported yet.
